# Make-your-own-OS
Make your own Operating System using my programming language and my tool built with Python!

________________
ENGLISH/ENGLISCH:
----------------

This engine and programming language were developed by Marian, also known as PokerHuhn.

You will need to install a few things, such as Python and QEMU.
On Windows, you must open the command prompt (CMD) and install the 'Pillow' library for Python.
You can do this using the following command:

pip install Pillow

There are small demo projects located in the 'Template_LWKOSSL-Kernel' folder.
Have fun developing the system!

Information:

The system is only compatible with Legacy BIOS and operates exclusively in 16-bit real mode, as it is still in the pre-alpha phase.
